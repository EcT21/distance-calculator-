# Distance-calculator-

## This calculates the distance between two points

## how to run
1. Open the program
2. Enter the required values for the program to solve (x1, y1, x2, y2)
3. Let the magic happen

## input needed
1. enter x1
2. enter y1
3. enter x2
4. enter y2

## sample outputs
x1 = 1
x2 = 2
y1 = 3
y2 = 4

The total distance of the two points is = 1.41
